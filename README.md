# Серверное приложение для просмотра афиши кинотеатра

## Flow
В проекте используется GitHub Flow, так как он хорошо подходит для команды из одного разработчика.

## Commits
В проекте принято соглашение Conventional Commits
```change_type(scope): message```

**Тип изменения**
- feat - новая функциональность
- fix - исправление бага
- docs - изменение документации
- style - правки по стилю
- refactor - рефакторинг кода
- perf - улучшение производительности
- test - покрытие кода тестами
- ci - изменение CI/CD пайплайна
- chore - прочие задачи (изменение .gitignore)
- revert - откат предыдущего коммита

- core
